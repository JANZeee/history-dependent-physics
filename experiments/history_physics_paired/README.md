# 两块看起来一样的试件，哪块先断？

我复用了前一轮的疲劳仿真。每对试件从同一裂纹长度开始，材料参数、过去平均载荷和未来每一步的载荷都相同。过去 60 步的载荷波动幅度不同，最后一起停载。模拟相机只拍到遮住裂纹的外壳，所以每对在预测起点的 RGB 像素相同。过去的画面也保持静止，这一版里能区分两块试件的信息来自载荷记录。

三组共用已有的疲劳更新式，并给定同一段未来载荷。画面组用下采样的 RGB 特征估计起点损伤，历史组的同形网络还看到逐步载荷，两组都用模拟器损伤作训练标签。真实损伤组直接从模拟器给出的起点推进。它和生成参考答案使用同一个公式，所以可用来核对起点信息充足时的表现。

训练、验证和两份测试分别用数据种子 31001、31002、31003、31004。训练为打乱的载荷序列，另一份测试把高低载荷放成连续段。每份测试 512 对，训练跑 101、202、303 三个种子。两块预测在同一步断时记为并列。所报断裂步从预测起点开始计数。

| 输入设置 | 打乱载荷排对先后 | 成段载荷排对先后 | 成段载荷断裂步 MAE |
|---|---:|---:|---:|
| 只看当前画面 | 512 对均并列 | 512 对均并列 | 9.82 步 |
| 观测和载荷历史 | 512 / 512 | 512 / 512 | 1.57 步 |
| 直接给真实损伤 | 512 / 512 | 512 / 512 | 0 步 |

排序结果在三个种子上一致，MAE 是三种子平均。成段测试换了载荷排列，沿用同一个材料模型和载荷幅值范围。参考公式按每步载荷的三次方累积损伤，网络对逐步特征取平均，两者都不区分同一组载荷的先后顺序。这里看到的是载荷历史在这套合成设定下提供的信息。

demo 在训练前按真实断裂时间差选取中位差附近的一对。它使用成段测试的第 3 号样本（从 0 开始）和模型种子 101。仿真里 A 第 34 步断、B 第 46 步断。当前画面组预测 44 / 44，历史组预测 34 / 45，真实损伤组预测 34 / 46。

在仓库根目录用已有实验的 Python 环境运行：

```bash
python -m experiments.history_physics_paired.run --output outputs/paired_fatigue
python -m experiments.history_physics_paired.render_demo --output outputs/paired_fatigue
```

输出目录有每个种子的指标、demo 样本和 GIF。安装 FFmpeg 时也会生成 MP4。在其他系统上可用 `--font` 指定支持中文的字体文件。
